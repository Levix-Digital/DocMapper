## Summary

Port the client-side logic from the reference application to the Copyx Vue 3 codebase. This involves replacing the current Tesseract-based extraction with the verified Regex logic, implementing PDF generation using `pdf-lib` with the embedded template, and simplifying the UI to a direct drag-and-drop workflow.

## Phase 0: Research & Decisions

**Decision**: Use `jsbarcode` for barcode generation.
**Rationale**: Used in reference app, lightweight, zero-dependency.

**Decision**: Use `jszip` for batch downloading.
**Rationale**: reference app uses it, standard for client-side zipping.

**Decision**: Embed template as Base64 string in code (or asset file).
**Rationale**: Avoids network fetch issues and 404s (referencing previous errors). Keeps app self-contained.

## Phase 1: Design

### Data Model (`modules/cmr/types.ts`)

```typescript
export interface CMRData {
  shipment: string;
  seal: string;
  trailer: string;
  consignments: string; // "MULTI" or comma-separated
  est_arrival_date: string;
  est_arrival_time: string;
}

export interface ProcessingResult {
    fileName: string;
    blob: Blob;
    data: CMRData;
}
```

### Logic Flow (`extractor.ts`)

1. **Input**: `pdfjsLib.getDocument(...)`.
2. **Loop**: For each page:
   - `page.getTextContent()`.
   - Stringify text items.
   - Run Regex patterns (Seal, Shipment, Consignments, Date/Time, Trailer).
   - Return `CMRData`.

### Logic Flow (`template-engine.ts`)

1. Load Embedded Template via `pdf-lib`.
2. Map `CMRData` fields to Form Fields.
3. Generate Barcode (Code 128) -> Canvas -> PNG -> Embed in PDF.
4. Flatten Form.
5. Return `Uint8Array`.
