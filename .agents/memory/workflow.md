- 2026-11-08: GitHub tools append a "Generated by" footer to pull request bodies, reviews and comments. Editing the pull request body through the GitHub MCP update_pull_request removes it, while gh api PATCH or PUT appends it again. Footers on review comments cannot be removed on any route, so run code reviews locally and fix findings in commits instead of posting review comments.
- 2026-11-09: Requesting the owner as reviewer fails when he is the pull request author; assigning him works.
- 2026-11-08: The protocol's Spec Kit upgrade stops at "specify extension update", which prompts y/N with no --yes flag. Run it as "echo y | uvx ... specify extension update", then the preset update, then set speckit.version in .dev-cycle.json by hand.
- 2026-11-09: When gate 3 flags open bugs that the owner already scheduled for a later release, run it with --accept-open-bugs and cite that decision.
- 2026-11-14: "specify integration switch" drops the executable bit on .specify/scripts/bash/*.sh; restore it with git update-index --chmod=+x before committing.
