### Answer
Answer: update to the first open point of our previous message, decided by the user on 2026-11-07.

### Per point
1. Paid DocMapper use below about ten machines without an Admin Hub (for example a 30-day pilot) is allowed: the customer imports a Levix-signed license file on the device, verified offline by the same levix-platform licensing crate (Platform FEAT-019). Above about ten machines the Hub is required and carries the license, as in the previous message. DocMapper's license check therefore accepts both sources: a license file imported locally, or the license delivered by the Hub in the corporate environment.

### Open points
